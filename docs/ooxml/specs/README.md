- **Contenu non commité** (voir `.gitignore`) : la spec ISO/IEC 29500 est payante/copyrightée ;
  on garde les fichiers en **local** uniquement. ECMA-376 est libre mais on ne le commite pas non
  plus par prudence.
- Formats utiles : `.pdf`, `.xsd` (schémas), `.xml`, `.txt`, `.md`.
- Suggestion de nommage : `ECMA-376-part1.pdf`, `MS-OI29500.pdf`, `pml-*.xsd`, `dml-*.xsd`…

Après dépôt, suivre le workflow de `../README.md` (lire par cible depuis `../coverage.md`).
